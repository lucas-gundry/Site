What I'm working on

The lab is a small, realistic company setup run on one mini PC. A fake shoe company gets attacked, my detections catch it, and an AI agent helps investigate, with a human approving every action that matters.

  • Identity as code: a 30-person company directory in Okta, managed with Terraform.
  • SIEM and detections: Okta's audit log flowing into Elastic, with detection rules written in Sigma and tested both ways (it fires when it should, and stays quiet when it shouldn't).
  • Reliability you can check: checks that alert me when logs go missing or a backup fails, and when the check itself stops running.
  • AI, run securely: a triage agent with read-only tools, hard limits on each run, and prompt-injection tests.
