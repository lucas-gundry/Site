How I work

I test access by trying things that should fail. If a monitoring account can delete backups, I want to find that out myself.

I keep security decisions in code. In my triage agent, the model summarizes and suggests, and code validates every tool call. The agent has no tools that change anything. Actions that would need my approval are designed but not built yet.

I check the logs before I call something done. In one test the Okta console showed a permission as granted. The audit log showed it wasn't, and the log was right.

When something looks broken, I measure it before I fix it, and I keep my notes when I turn out to be wrong. One of my write-ups is about that.

I keep secrets out of my repos and my logs. Every push to this site runs gitleaks and a check for internal hostnames and IDs.
