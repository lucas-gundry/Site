The lab

Everything runs on one mini PC at home. The story is a fake shoe company that gets attacked. My detections should catch the attack, and the agent helps me investigate it. The agent can read data and suggest what to do. It has no tools that change anything; actions that would need my approval are designed but not built yet.

Done so far:

  • An Okta directory for the fake company, with 30 users in 8 departments and 13 groups, all managed in Terraform.
  • Okta's audit log streams into Elastic. Every hour a separate check confirms each event arrived, matching by event ID.
  • Detections written as code, with test cases that run on every pull request: failed Okta sign-ins, SSH failures and sudo as another user are live. An MFA push fatigue rule is written and tested, but not turned on yet.
  • Nightly snapshots of the SIEM, with a daily check that emails me if a backup fails or the check stops reporting.
  • An AI triage agent that checks for new alerts every 5 minutes, investigates with read-only tools and posts a verdict to Slack. It's capped at 15 tool calls per run. Its tests assume the model obeys injected text, then check that code rejects what it asks for.
  • IP addresses, places and outside email addresses leave the agent's tools as stand-ins. A separate check emails me if the agent stops, a run fails or a key is about to expire.
